not new timings or relabeled historical measurements. `summary.json` records

decompression reconstructs every recorded byte. Command filenames and raw

not copied execution timestamps; the remaining copied files retain their
original filesystem timestamps. Python's `gzip.open(path, 'rt')` reads them

`../specialization-campaign/cases.tsv`; they are not newly generated results.

repository root. Every binding matches the included root artifact files.
