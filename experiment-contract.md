# Experiment contract

## Decision and purpose

The project follows the **negative-result / technical-report route**.  The
preserved finite checker remains a valid bounded result.  The added Java study
tests whether ordinary passive `ObjectInputStream` observations supply the
complete write, root, callback, and identity evidence assumed by that checker.
The falsification criterion is simple: any executed Java mechanism that cannot
be represented without inventing observations must cause the bridge to return
`UNKNOWN`, not be coerced into the abstract model.

## Fixed finite experiment

- Heap size: complete enumeration at 2 and 3 objects; admission bound 128.
- Record: `(ready,value,next)` with two bits and one nullable object index.
- Roots: bounded input collection; exact `int` type and range checked before
  deduplication.
- Predicate: `ready(o) && (next(o)==null || value(o)<=value(next(o)))`.
- Candidate events: one field assignment and optional root addition.
- Checker premise: authentic complete events and retained roots, protected
  checker state, and atomic abstract commit.
- Comparison: every candidate against an independently coded dense oracle.
- Selection: deterministic full census; no random seed, train/test split, or
  outcome-dependent filtering.

## Concrete Java study

- Mechanism: ordinary `ObjectOutputStream`/`ObjectInputStream` with locally
  authored `Serializable` classes, plus one compatible class-evolution stream.
- Input: only in-memory or temporary files generated by the harness itself.
- Version scope of recorded evidence: Debian OpenJDK 21.0.11; no cross-JDK
  equivalence claim.
- Observations: owned `readObject` entry/exit and post-default state,
  `readResolve`, an enabled `resolveObject` override, returned root, exception,
  owned early-publication side effect, identity/alias facts, and final snapshot.
- Mapping: an independent fail-closed translator returns `MAPPED` only for a
  narrow, complete owned final snapshot; otherwise `UNKNOWN`.
- Required negative controls: aliasing, missing field, type/shape mismatch,
  callback order, unfinished peer read, illegal root input, observation gap,
  closed failure, and failure after escape.
- No exploit payloads, third-party targets, network inputs, native hooks,
  unrestricted reflection, external services, GPUs, or model APIs.

## Independence

`src/java_trace_bridge.py` imports neither the certificate producer nor the
production checker nor the dense oracle.  The runner invokes the oracle and
checker only after the bridge has returned a bounded snapshot.  The producer,
checker, oracle, whole-path witness oracle, and Java bridge remain distinct code
paths.  This is separation within one research execution, not independent
external validation.

## Reproduction and failure policy

Both documented runners require an absent or empty output directory and record
actual environment information before scientific execution.  The original
canonical campaign's architecture and exact Python/JDK versions are unknown;
later machine facts must not be backfilled.  A nonzero command, timeout,
resource cutoff, mismatch, malformed observation, missing callback coverage, or
unsupported Java feature is failure/`UNKNOWN`, never evidence of safety.

## Claims permitted by this contract

Permitted: finite-domain agreement counts, named negative controls, exact replay
results, and the partial snapshot-encoding proposition under stated completeness
assumptions.

Not permitted: constructor-history attestation, complete JVM trace coverage,
production deserialization enforcement, rollback of arbitrary callback side
effects, universal Java compatibility, or an established novel TIFS research
contribution.
